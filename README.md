# META DX SCHOOL - React Structure

Ce projet est une structure React initialisée avec Vite et TypeScript, suivant le design demandé.

## 📁 Structure du Projet

- **src/components/layout/** : Composants globaux (Navbar, Footer, Layout)
- **src/pages/** : Les pages de l'application (Home, CFA, Conseils & Formations, etc.)
- **src/styles/** : Fichiers CSS (Global, Navbar, Home)
- **src/assets/** : Images et ressources

## 🛠 Technologies

- **React** (v18+)
- **Vite** (Build tool)
- **TypeScript** (Typage)
- **Vanilla CSS** (Styles modulaires et variables globales)
- **React Router DOM** (Navigation)
- **Lucide React** (Icônes)

## 🚀 Démarrage

1. Installer les dépendances :
   ```bash
   npm install
   ```

2. Lancer le serveur de développement :
   ```bash
   npm run dev
   ```

3. Construire pour la production :
   ```bash
   npm run build
   ```

## 🎨 Design

Le design respecte la charte graphique :
- Couleurs violettes et dégradés.
- Typographie "Inter".
- Navigation avec indicateurs actifs.
